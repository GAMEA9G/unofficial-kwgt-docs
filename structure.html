File structure

A preset has preset_info (who and how big) and preset_root (the layers). First item in any list = bottom layer.

{
  "preset_info": { "version": 13, "title": "My Widget", "width": 400, "height": 200 },
  "preset_root": {
    "internal_type": "RootLayerModule",
    "viewgroup_items": [ ]
  }
}
preset_infoMeaning
versionUse 13. 11 and 12 also appear in real files.
title / description / author / emailShown in the KWGT list. Email may be empty.
width / heightCanvas pixels. Generated files use them, but the real Calendar preset has neither and sizes everything from si(rwidth) and si(rheight). In a generated file, 0 or missing may give a blank widget. Home-screen mapping is undocumented.
lockedtrue stops users editing layers.
featuresTags like "MUSIC NOTIFICATIONS BLUETOOTH". Empty string is fine.
release, archive, pflags, xscreens, yscreensInternal. Files without them load.
preset_rootMeaning
internal_type"RootLayerModule" in a widget preset. In komponent.json it is "KomponentModule" (see Komponents).
viewgroup_itemsModules directly in the root.
globals_listOptional global variables (an object).
internal_eventsGlobal taps. type may be omitted.
config_scale_valueEditor scale. Not required.

The .kwgt package

MyWidget.kwgt (ZIP)
├── preset.json   (required, ZIP root)
├── preset_thumb_portrait.jpg
├── preset_thumb_landscape.jpg
├── bitmaps/  fonts/  icons/   (optional)

Link bundled files with kfile://org.kustom.provider/widgets/MyWidget.kwgt/fonts/Custom.ttf. Renaming the .kwgt breaks these links. Built-in fonts skip the name: kfile://org.kustom.provider/fonts/ProductSans-Medium.ttf. Whether KWGT loads a file without thumbnails is unconfirmed.
