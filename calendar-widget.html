Calendar widget

A Nothing-inspired calendar by Georg9741 (RootLayerModule, version 13, features: "CALENDAR"). Its preset_info has no width or height: everything is sized from the widget itself with si(rwidth) and si(rheight). It shows up to three events from the current month and a "Nothing planned" state.

1. Layout

Root (tap: KUSTOM_ACTION)
├─ Header (Overlap)
│   ├─ background RECT (full widget, rounded)
│   ├─ Touch Area (transparent RECT, opens Calendar app)
│   ├─ Month text  $df(MMMM)$
│   └─ Add Event (circle + "+", opens a link)
└─ Calendar Info (Stack)
    ├─ Event 1   (stack: Date circle + Event pill)
    ├─ Event 2
    ├─ Event 3
    └─ No Event  (shown when the month has none)

2. Sizes: skpi and rwidth

Sizes are written like $80/si(skpi)$ or $si(rwidth)-140/si(skpi)$. My reading: si(skpi) is a screen density factor, so a design number divides by it to stay the same visual size. si(rwidth) and si(rheight) make boxes fill the widget. The only global is corners (NUMBER, 0 to 160, default 48), used as $gv(corners)/si(skpi)$.

3. Material You colors

Colors come from the system palette: si(syscn1, tone). The second number is a tone from dark (10) to light (95). My reading of the usage:

FormulaUsed for
$si(syscn1, 10)$Widget background, text on the "+" button
$si(syscn1, 20)$Event pill, date circle
$si(syscn1, 30)$Pill for all-day events
$si(syscn1, 70)$Hint text
$si(syscn1, 95)$Main text and "+" circle
#FFD71921Fixed red accent for today

4. One row, copied: si(mindex)

Event 1, 2 and 3 are identical JSON. They differ only through si(mindex, n). Reading every use in the file, n counts levels up: si(mindex) is the module’s own position in its parent, and si(mindex, 3) is the position of its great-grandparent. Inside an Event stack that is the event number, so the same formula fetches event 0, 1 or 2.

ModuleCallReaches
Event stack itselfci(start, si(mindex))its own index (0, 1, 2)
Date circle (1 level in)si(mindex, 1)the Event stack
Shape inside Datesi(mindex, 2)the Event stack
Text inside Text inside Eventsi(mindex, 3)the Event stack

5. Calendar info: ci()

ci(field, index) reads an event. Fields used: title, start, end, allday, url, urld (the day link). Example: $ci(title, si(mindex, 3))$.

6. Showing and hiding: ALWAYS, NEVER, REMOVE

config_visible returns a third value here, REMOVE. My reading: NEVER hides but keeps the space, REMOVE takes it out of the stack so rows below move up.

Event stack: "$if(df(MMMM, ci(start, si(mindex)))=df(MMMM), ALWAYS, REMOVE)$"
Date circle: "$if(df(D, ci(start, si(mindex, 1)))=df(D, ci(start, si(mindex, 1)-1)), NEVER, ALWAYS)$"
No Event:    "$if(df(MMMM, ci(start, 0))=df(MMMM), REMOVE, ALWAYS)$"

So an event row is removed unless it is in this month, a second event on the same day hides its date circle (but keeps the alignment), and "No Event" appears only when the first event is not in this month. Today’s date circle turns red with $if(df(D, ci(start, ...))=df(D), #FFD71921, si(syscn1, 20))$.

7. Text tricks

  • Two lines in one formula: $df(E\nd, ci(start, ...))$ puts the weekday above the day number. The \n sits inside the format.
  • Fixed-width text: text_size_type: "FIXED_WIDTH" with text_width and text_lines (1.0 or 2.0) keeps long titles inside the pill. text_align: "CENTER" is now verified.
  • Clipping: a RECT named .Clip Text with fx_mask: "CLIP_ALL" sits in the overlap to clip the text.
  • Time range: df(hh:mm, start)-df(hh:mm, end) stays text, giving something like 09:00-10:00. It is hidden for all-day events.
  • Fonts: kfile://org.kustom.provider/fonts/NDot57Caps.otf and NDot55Caps.otf. These are not bundled; install the fonts in KWGT’s fonts folder.

8. Taps

{ "action": "KUSTOM_ACTION" }                       // root
{ "action": "LAUNCH_APP", "intent": "intent:#Intent;action=android.intent.action.MAIN;category=android.intent.category.LAUNCHER;component=com.google.android.calendar/com.android.calendar.AllInOneActivity;S.org.kustom.intent.label=Calendar;end" }
{ "action": "OPEN_LINK", "url": "$ci(url, si(mindex, 1))$" }   // url can be a formula

A transparent shape (#00000000) named Touch Area carries the app launch, so a tap target does not need to be visible. The "No Event" date button builds its URL by joining quoted text with +: $"intent://com.android.calendar/time/"+df(S)+"000#Intent;scheme=content;end"$. Quotes plus + join text here, even though results elsewhere are bare words.

9. Make it show more events

  1. Copy the "Event 3" stack and rename it. Nothing inside needs changing.
  2. Update the Calendar Info spacing formula, which counts three rows: (si(rheight)-(80+80+80+128+24)/si(skpi))/2. Add another 80 per row.
