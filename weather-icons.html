Weather icons komponent

Weather Now Icons (by Grabster Studios) is an icon pack komponent: 45 PNGs, three settings, and a single module that picks the right PNG. It is the clearest example of how globals, formulas and bitmaps work together. License: CC BY-SA 4.0, so credit the authors if you reuse it (their names are in the file’s README global).

1. The package

Folder layout is on the Komponents page: komponent.json, komponent_thumb.jpg and bitmaps/ with 15 conditions x 3 files. preset_info here is version: 11 (so 11, 12 and 13 all appear in real files), width/height: 75, features: "WEATHER".

2. The three settings

GlobalTypeWhat the user picks
iconLISTWhich weather: Current ($wi(icon)$) or the forecast for day 0 to 9 ($wf(icon, n)$). Default $wi(icon)$.
daytimeLISTNone, Day (1), Night (0) or Auto ($ai(isday)$). Default Auto.
sizeNUMBER8 to 1024, default 96.

3. New global types: LIST and BITMAP

TypeFieldsNotes
LISTentries, valueentries is a comma-separated list of value##Label. The value can be a formula. The $+$ entry labeled None is the empty choice. Quote entries that contain commas (see the README global).
BITMAPvalue, toggles: 1value is a kfile:// path to an image.
"icon": { "index": 2, "type": "LIST", "title": "Icon", "description": "weather forecast",
  "entries": "$wi(icon)$##Current,$wf(icon, 0)$##Today Forecast,$wf(icon, 1)$##Tomorrow Forecast,...",
  "value": "$wi(icon)$" },
"daytime": { "index": 3, "type": "LIST", "title": "DayTime",
  "entries": "$+$##None, 1##Day, 0##Night, $ai(isday)$##Auto day/night",
  "value": "$ai(isday)$" },
"icon/clear1": { "index": 7, "type": "BITMAP", "title": "CLEAR1", "toggles": 1,
  "value": "kfile://org.kustom.provider/bitmaps/CLEAR1.png" }
Resolved. Global names may contain a slash (icon/clear). Komponent bitmap paths here are kfile://org.kustom.provider/bitmaps/NAME.png with no widget or komponent name in the path, unlike the widget examples. Presumably KWGT resolves them against the package; I have not seen how.

4. The naming trick

Every condition has three globals: icon/clear (no sun or moon), icon/clear1 (day) and icon/clear0 (night). The suffix is the same 1 or 0 the DayTime setting produces. That answers last turn’s question: 1 = day, 0 = night. Pick values and see which file is used:

Emoji is only a stand-in. The real icons are the PNGs in bitmaps/.

5. The one module

{
  "internal_type": "BitmapModule",
  "internal_toggles": { "bitmap_bitmap": 10, "bitmap_width": 100, "bitmap_height": 100 },
  "internal_globals": { "bitmap_width": "size", "bitmap_height": "size" },
  "internal_formulas": { "bitmap_bitmap": "$gv(icon/gv(icon)+gv(daytime))$" },
  "bitmap_scale_mode": "CENTER_FIT"
}
  • The formula builds a global name from text: gv(icon) gives clear, gv(daytime) gives 1, the + joins them into icon/clear1, and the outer gv(...) returns that BITMAP global. This is how a whole icon set needs only one module.
  • Width and height use the size global (toggle 100).
  • bitmap_scale_mode: "CENTER_FIT" fits the image inside the box, centered. This is the first bitmap fit mode seen in a real file.
  • The root has "internal_toggles": {"config_scale_value": 1}, so that toggle can sit on a komponent root.

6. Quirks in the file

  • Indexes are loose: icon/hail0 and icon/rain1 both use 31, and 5, 9, 10, 38 are unused. KWGT still loads it, so indexes only affect order.
  • ai(isday) is new in these docs. It returns the day/night state (1 or 0 by the entry labels). I assume ai is astronomy info.
  • A README LIST global (description, GitHub, license, contributors) is a handy way to ship notes inside the editor.

7. Make your own icon pack

  1. Put PNGs in bitmaps/ with names like NAME.png, NAME1.png, NAME0.png.
  2. Add one BITMAP global per file, keyed icon/name.
  3. Add LIST globals for the source and day/night, and a NUMBER for size.
  4. Use one BitmapModule with the gv(icon/gv(icon)+gv(daytime)) formula.
  5. Zip the folder contents (komponent.json at the root) and rename to .komp.
