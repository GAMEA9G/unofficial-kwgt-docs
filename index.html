KWGT preset.json docs

A friendly, example-first guide to the Kustom Widget Maker preset format (schema 13). Code boxes are editable and have live previews.

Previews come from a small simulator (shapes, text, icons, anchors, stacks, globals, toggles, taps, and the formulas df, bi, mi, gv, if). Real KWGT does more, so test on your phone. Unconfirmed properties are labeled.
