KWGT preset.json Schema

This is the complete, definitive schema documentation for the Kustom Widget Maker (KWGT) preset.json file format (Schema Version 13). This documentation covers all properties observed across standard, weather, and media player widgets, including exact edge-case behavior and file packaging.

1. preset_info (Root Metadata)

The root object containing metadata about the widget's dimensions, author, and display settings.

PropertyTypeDescription
versionNumberThe schema version. Currently 13.
titleStringThe name of the widget displayed in the KWGT list.
descriptionStringA brief description of the widget.
authorStringName of the creator.
emailStringContact email of the creator.
width / heightNumberThe base canvas dimensions in pixels (e.g., 916 x 542).
lockedBooleanIf true, the user cannot edit the widget layers.
featuresStringSpace-separated tags (e.g., "WEATHER FORECAST").
releaseNumberInternal release ID.
archiveStringUsually null. References a Kustom asset archive.
pflagsNumberInternal bitmask flags (e.g., lock screen widget behavior). Usually 0.
xscreens / yscreensNumberDefines if the widget spans across multiple home screen pages.

2. preset_root (Root Container)

The absolute base of the widget layout.

PropertyTypeDescription
internal_typeStringMust be "RootLayerModule".
globals_listObjectContains all global variables (themes, responsive sizing).
viewgroup_itemsArrayAn array of all visual modules directly inside the root.
internal_eventsArrayGlobal touch actions. Can be defined without a "type" property at the root level.
config_scale_valueNumberThe internal editor scaling factor. Critical for retaining the exact size the author designed.

3. globals_list (Global Variables)

Allows you to define reusable variables for colors, sizes, and text.

PropertyTypeDescription
indexNumberThe order index. Does not always start at 1 (especially inside Komponents).
typeStringCOLOR, NUMBER, TEXT, FONT.
titleStringThe name used in formulas via $gv(name)$.
descriptionString(Optional) Description shown in the KWGT editor.
valueMixedThe static fallback value. Can be omitted if global_formula is used.
global_formulaStringA KWGT math formula that calculates the value dynamically.
min / maxNumberRestricts the allowable slider range. Note: Not all globals require these properties.
togglesNumberUsually 10. Indicates the variable is dynamic.

4. Common Module Properties

Every visual element in KWGT is a Module. They share these common properties for positioning:

PropertyTypeDescription
internal_titleStringThe layer name shown in the KWGT editor.
position_anchorStringTOPLEFT, CENTER, BOTTOMRIGHT, TOPRIGHT, BOTTOMLEFT, CENTERRIGHT, BOTTOM.
position_offset_x / _yNumberShifts the module outwards from its anchor point.
position_padding_*NumberDistance from the anchor to the content inward. (Padding is applied *before* offset).

4.1 OverlapLayerModule

Stacks child elements on top of each other (Z-Index layout).

PropertyTypeDescription
viewgroup_itemsArrayThe child modules that overlap inside this container.
fx_maskString"CLIP_ALL" to clip all children. "CLIP_NEXT" to clip only the immediate next layer.
config_visibleStringUsed with ALWAYS or NEVER to toggle module visibility.
config_fx_radiusNumberApplies a corner radius mask to the container itself, clipping all its children to that shape.

4.2 StackLayerModule

Lines up child elements sequentially (Flexbox layout).

PropertyTypeDescription
config_stackingStringVERTICAL_CENTER, HORIZONTAL_CENTER, etc.
config_marginNumberSpacing between items. Supports negative float values (e.g., -4.4) to force overlapping.
config_scale_valueNumberInternal editor scaling factor for this specific stack.

4.3 KomponentModule

A reusable widget block. Acts like a group but has its own scoped globals.

PropertyTypeDescription
globals_listObjectGlobals scoped strictly inside this Komponent (isolated from Root globals).
internal_descriptionStringA description of the Komponent's purpose.
internal_formulasObjectUsed to set config_visible.

4.4 ShapeModule

Draws geometric shapes, backgrounds, and progress bar components.

PropertyTypeDescription
shape_typeStringRECT, OVAL, CIRCLE, EXAGON, ARC, PATH.
shape_width / _heightNumberDimensions in pixels/DP.
shape_cornersNumberCorner radius. 360 makes it fully rounded.
shape_angleNumberAngle of the arc in degrees (required for ARC).
shape_rotate_modeStringe.g., "DEG180" (flips an arc to make a wave).
paint_colorStringHex color #AARRGGBB.

4.5 TextModule / CurvedTextModule

Displays static text, dynamic formulas, or media info.

PropertyTypeDescription
text_expressionStringThe text or formula. Supports BBcode (e.g., "[b]Text[/b]").
text_familyStringThe font path (e.g., "kfile://...").
text_sizeNumberFloat value (e.g., 32.0).
text_alignStringLEFT, CENTER, RIGHT.
paint_colorStringHex color.
fx_shadowStringText can cast shadows: "OUTER".

4.6 BitmapModule

Displays images or album covers.

PropertyTypeDescription
bitmap_bitmapStringFile path or formula (e.g., "$mi(cover)$").
bitmap_width / _heightNumberDimensions.
bitmap_filterString"COLORIZE" applies a tint.
bitmap_filter_colorStringThe color to tint the image with.

4.7 FontIconModule

Displays vector icons from an icon font file.

PropertyTypeDescription
icon_iconStringThe icon name (e.g., "skip_next"). Can be a formula.
icon_sizeNumberSize in pixels.
icon_setStringPath to the icon font.

5. Global Bindings & Overrides

Any property can be overridden by a Global Variable or a Formula.

internal_toggles

A bitmask (e.g., 100, 10, 0) that tells KWGT which properties are active. If a formula is applied to a property, its toggle must be set.

"internal_toggles": {
  "paint_color": 100,
  "shape_width": 10
}

internal_globals

Binds a property directly to a global variable name.

"internal_globals": {
  "paint_color": "accent"
}

internal_formulas

Overrides a property with a dynamic mathematical calculation or multi-line script.

"internal_formulas": {
  "shape_corners": "$gv(side)/9$"
}

6. Advanced FX & Masks

Applied mostly to ShapeModule and containers.

PropertyTypeDescription
fx_maskStringCLIP_ALL (clips all children), CLIP_NEXT (clips the immediate next layer).
fx_gradientStringRADIAL, LINEAR, BITMAP.
fx_gradient_bitmapStringPuts an image inside the gradient.
fx_bitmap_dimNumberControls the opacity/darkness of the bitmap overlay.
fx_gradient_offsetNumberControls the spread position of the gradient.
fx_shadowStringOUTER or INNER.
fx_shadow_colorStringHex color of the shadow.
fx_shadow_blurNumberBlur radius.
fx_shadow_distanceNumberDistance the shadow is cast.
fx_shadow_directionNumberAngle direction of the shadow.

7. Events (internal_events)

Used to add touch interactions to any module.

PropertyTypeDescription
typeStringSINGLE_TAP, DOUBLE_TAP, LONG_TAP. (Can be omitted at the Root level).
actionStringLAUNCH_APP, MUSIC, KUSTOM_ACTION, DISABLED.
music_actionStringIf action is MUSIC: NEXT, PREVIOUS, OPEN_APP.
intentStringAndroid Intent URI for launching apps.

FunctionDescriptionExample

9. Edge Cases & Undocumented Mechanics

These are specific quirks found in the JSON files that the compiler must handle correctly.

1. Multi-line Scripts in Formulas
internal_formulas can contain line breaks (\n) to execute sequential logic.
2. Built-in Globals (e.g., h)
In the Weather widget, shape_height is bound to a global named h. h and w are built-in KWGT variables representing the Root widget's height/width.
3. The config_visible Toggle Trap
Setting a formula for config_visible does nothing unless "config_visible": 10 is present inside internal_toggles.
4. Global Scope Isolation in Komponents
A KomponentModule can have its own globals_list. These globals do not leak to the Root, and their indices often start at numbers other than 1.
5. Font File Paths
All font and image paths use the kfile:// protocol.

10. Absolute Edge Cases & Exact Quirks

These represent the deepest structural anomalies in the JSON files that a compiler must replicate exactly.

1. Two-Line Script Formulas
In the Media Player progress bar, a formula uses \n to create a local variable on one line and evaluate it on the next: 
"internal_formulas": {
  "position_padding_left": "$lv(\"w\",gv(pbwidth)*(mi(percent)/100))$\n$if(lv(w)<=0, \"0\", lv(w)-8)$"
}
If the \n is stripped or converted to a space, KWGT will throw a formula error.
2. Negative Float Precision
Stack margins are highly precise floats. In the Media Player, the wave effect relies on: "config_margin": -4.4 The compiler must preserve this exact decimal value.
3. Exact Shape Spelling
The Weather widget explicitly uses "shape_type": "EXAGON" (not HEXAGON). The Media Player uses "CIRCLE" instead of OVAL. Do not autocorrect these spellings.

11. Fallbacks & Event Variations

Anomalies regarding static properties and root events.

1. Static Fallbacks Coexisting with Globals
Even when a property is bound to a global variable or formula, KWGT still expects the static property to be present as a fallback. In the Time Date Info widget, the "BG" shape has both a global binding and a static color: 
"internal_globals": {
  "paint_color": "bgcolor"
},
"paint_color": "#FF000000"
The compiler must always output a valid static paint_color (or equivalent) even if it is fully overridden.
2. Root Event Variations (Missing `"type"`)
The root internal_events array is highly inconsistent across widgets. Variation A (Time Date Info): No type, uses KUSTOM_ACTION. 
"internal_events": [
  { "action": "KUSTOM_ACTION" }
]
Variation B (NothingTemp): Explicit type, disabled action. 
"internal_events": [
  { "type": "SINGLE_TAP", "action": "DISABLED" }
]
Variation C (Media Player): No type, but specifies a music action. 
"internal_events": [
  { "action": "MUSIC", "music_action": "OPEN_APP" }
]
The compiler must not assume "type": "SINGLE_TAP" is required at the Root level.

12. Final Structural Variations

The last remaining edge-cases found in the Media Player and Date widgets.

1. Missing Static Properties (No Fallback)
While the Date widget included a static fallback paint_color, the Media Player progress bar "Clip Bg" shape explicitly omits the static property entirely, relying only on the global: 
"internal_type": "ShapeModule",
"internal_toggles": { "paint_color": 100, "shape_width": 10 },
"internal_globals": { "paint_color": "fg-color" }
// NO "paint_color" static property exists here.
The compiler must be capable of omitting the static fallback if the original Penpot node doesn't have one.
2. Container-Level Events
Events are not limited to the Root or Leaf shapes. The Media Player attaches an event to an OverlapLayerModule named "Output": 
"internal_type": "OverlapLayerModule",
"internal_title": "Output",
"internal_events": [
  { "type": "SINGLE_TAP", "action": "MUSIC", "music_action": "OPEN_APP" }
]
Any module type can accept an internal_events array.
3. Custom Font Paths in Icons
The FontIconModule can point to a custom font bundled inside the widget's own ZIP archive, rather than the system font: 
"icon_set": "kfile://org.kustom.provider/widgets/Material3_Media_Player.kwgt/icons/material.ttf"
4. Text Modules Use Shape FX Shadows
Text modules (CurvedTextModule) use the exact same shadow FX properties as Shape modules: 
"fx_shadow": "OUTER",
"fx_shadow_blur": 41,
"fx_shadow_direction": 0,
"fx_shadow_distance": 0,
"fx_shadow_color": "#80000000"

13. Package & Install (The .kwgt Container)

To build a functioning KWGT widget, the preset.json cannot stand alone. It must be packaged inside a specific ZIP structure and renamed with the .kwgt extension.

How to Package the Widget

Creating a .kwgt file is as simple as zipping the contents (not the parent folder) and renaming the extension.

  1. Create a folder on your computer (e.g., MyAwesomeWidget).
  2. Inside this folder, place your preset.json.
  3. If your widget uses images or custom fonts, create a folder named bitmaps for images and fonts for fonts, and place the files inside them.
  4. Select all files/folders inside MyAwesomeWidget and right-click to Compress/Zip them.
  5. Rename the resulting .zip file to MyAwesomeWidget.kwgt.

Directory Structure

When a user extracts your .kwgt file, KWGT expects the following structure:

MyWidget.kwgt (ZIP archive)
│
├── preset.json (Required)
├── bitmaps/ (Optional - for images)
│ ├── image1.png
│ └── album_cover.jpg
└── fonts/ (Optional - for custom fonts)
└── MaterialIcons-Regular.ttf

Linking Files via `kfile://`

When you include images or fonts in the ZIP, you cannot reference them with a normal file path. KWGT requires the kfile:// protocol.

How paths resolve inside KWGT:
If you bundle a font inside the ZIP, the reference in preset.json must point to the location of the .kwgt file on the user's device. Because the widget is installed to /Kustom/widgets/MyWidget.kwgt, the reference path looks like this: 
"text_family": "kfile://org.kustom.provider/widgets/MyWidget.kwgt/fonts/CustomFont.ttf"
"bitmap_bitmap": "kfile://org.kustom.provider/widgets/MyWidget.kwgt/bitmaps/image1.png"
If you bundle system fonts (like Product Sans) that are built into KWGT, you omit the widget name: 
"text_family": "kfile://org.kustom.provider/fonts/ProductSans-Regular.ttf"

Installing the Widget

Once the .kwgt file is created:

  1. Transfer the .kwgt file to your Android device.
  2. Move the file into the Kustom > widgets folder on your phone's internal storage. (e.g., Internal Storage/Kustom/widgets/MyAwesomeWidget.kwgt).
  3. Open the KWGT app. Go to the "Installed" or "Library" tab.
  4. Your widget should appear in the list. Tap it to load it.
  5. Add a KWGT widget to your home screen, select your preset, and tap Save.
