KWGT preset.json Schema

Schema documentation for the Kustom Widget Maker (KWGT) preset.json format (schema version 13), reverse-engineered from standard, weather and media player presets, then checked against a real Material3 Media Player preset (916 x 542) and against presets generated by a Penpot plugin and loaded into KWGT.

How to read the badges. verified means the property or behaviour appears in a real preset or a generated file loaded in KWGT. unconfirmed means it is documented from earlier observation but was not seen in the real media player preset. Everything else is a plain description. Changes in this revision are mostly corrections: globals_list is an object, the toggle values are now defined, play/pause events and mi(state) values are listed, and bitmaps use formulas through internal_formulas.

1. preset_info (Root Metadata)

Metadata about the widget's dimensions, author and requirements.

PropertyTypeDescription
versionNumberSchema version. 13 in the real preset. Files written with 12 also load verified.
titleStringName shown in the KWGT list verified.
descriptionStringShort description verified.
authorStringCreator name.
emailStringCreator contact. May be an empty string verified.
widthNumberBase canvas width in pixels (916 in the real preset). Must be greater than 0. How it relates to the size KWGT gives a widget on the home screen is not documented. See section 14.
heightNumberBase canvas height in pixels (542 in the real preset). Must be greater than 0.
lockedBooleanIf true, the user cannot edit the layers.
featuresStringSpace-separated feature tags, for example "MUSIC NOTIFICATIONS BLUETOOTH" or "WEATHER FORECAST". An empty string loads verified.
releaseNumberInternal release ID, a large integer (377432414 in the real preset). Files without it load verified.
archiveStringUsually null. References a Kustom asset archive.
pflagsNumberInternal bitmask flags. 0 in the real preset.
xscreens / yscreensNumberHome screen page span. 0 in the real preset. Files that omit them load verified.

2. preset_root (Root Container)

The base of the widget layout. In the real media player the root holds a single KomponentModule named "Media Player", which holds all visual modules. Presets can also put modules straight in the root verified.

PropertyTypeDescription
internal_typeStringMust be "RootLayerModule" verified.
globals_listObjectGlobal variables, an object keyed by global name (section 3). Optional. The real preset keeps its globals on the Komponent and has none here.
viewgroup_itemsArrayAll modules directly inside the root. The first item is the bottom layer verified.
internal_eventsArrayGlobal touch actions. The type may be omitted at root level verified.
config_scale_valueNumberEditor scaling factor (88.0844 in the real preset). Files without it load verified, so it is not required.

3. globals_list (Global Variables)

Reusable variables for colors, sizes and text. It is an object keyed by the global's name, not an array verified. The key matches the entry's title.

PropertyTypeDescription
indexNumberOrder index. Values need not be contiguous or start at 1 (the real preset uses 4, 5, 6, 7, 8, 10, 12, 13).
typeStringCOLOR, NUMBER, TEXT, FONT. COLOR and NUMBER seen verified.
titleStringName used in formulas via $gv(name)$ and in internal_globals.
descriptionStringOptional text shown in the KWGT editor.
valueMixedStatic value. Omitted when global_formula is used.
global_formulaFormulaFormula that computes the value, for example $si(rwidth)/2.4$.
min / maxNumberOptional slider range, for example 0 to 720.
togglesNumber10 when the global is driven by global_formula verified.
"globals_list": {
  "fg-color": { "index": 4, "type": "COLOR", "title": "fg-color", "value": "#FFFFFFFF" },
  "bg": { "index": 6, "type": "COLOR", "title": "bg", "toggles": 10, "global_formula": "$si(syscn1, 20)$" },
  "pbwidth": { "index": 13, "type": "NUMBER", "title": "pbwidth", "description": "Progress Bar Width",
               "min": 0, "max": 720, "toggles": 10, "global_formula": "$si(rwidth)/2.4$" }
}

4. Common Module Properties

Every visual element is a module. They share these positioning properties:

PropertyTypeDescription
internal_titleStringLayer name shown in the editor.
position_anchorStringObserved: TOPLEFT, TOPRIGHT, CENTERLEFT, CENTERRIGHT, BOTTOM, BOTTOMLEFT, BOTTOMRIGHT verified. CENTER is also used by earlier presets. Modules with no anchor use the default.
position_offset_x / _yNumberMoves the module from its anchor. With TOPLEFT these are the x and y position from the top-left corner verified.
position_padding_left / _top / _right / _bottomNumberDistance inward from the anchor edge. TOPRIGHT with position_padding_right 36 and position_padding_top 36 sits 36 px from the top-right corner verified. Padding is applied before offset.
Draw order. The first item in any viewgroup_items array is the bottom layer and the last is on top verified. In the real preset "Background" comes before "Cover Fill" and "Gradient Overlay".

4.1 OverlapLayerModule

Stacks children on top of each other (z-index layout).

PropertyTypeDescription
viewgroup_itemsArrayChild modules, drawn first = bottom.
fx_maskStringCLIP_ALL clips all children, CLIP_NEXT clips only the next layer verified. In the real preset a shape with CLIP_NEXT masks the wave drawn after it.
config_visibleFormulaVisibility. Needs "config_visible": 10 in internal_toggles. Value is ALWAYS or NEVER, for example $if(mi(state)!=PLAYING, ALWAYS, NEVER)$ verified.
config_fx_radiusNumberCorner radius mask applied to the container and its children (10.0 in the real preset) verified.
internal_eventsArrayTouch actions. Any module type accepts them verified.

How a container works out its own size from its children is unconfirmed.

4.2 StackLayerModule

Lines up children one after another.

PropertyTypeDescription
config_stackingStringOnly HORIZONTAL_CENTER appears in the real preset verified. VERTICAL_CENTER is unconfirmed.
config_marginNumberSpacing between items. Seen: 8.0, 18.0, 24.0, 32.0 and the negative -4.4, which forces overlap verified.
config_scale_valueNumberEditor scaling factor for this stack.
position_*NumberAnchor and padding work on stacks too verified.

4.3 KomponentModule

A reusable block with its own scoped globals. The real media player wraps the whole widget in one.

PropertyTypeDescription
internal_titleString"Media Player" in the real preset.
globals_listObjectGlobals scoped to this Komponent, keyed by name. They do not leak to the root.
internal_descriptionStringPurpose of the Komponent, for example "Simple media player with configurable buttons".
internal_formulas / internal_togglesObjectVisibility. The real preset has "config_visible": "if(br(niagara-launcher, media-player) = \"true\", ALWAYS, NEVER)" with the toggle at 0, so the formula is stored but inactive verified.

This formula has no $...$ wrapper, so formulas in internal_formulas can appear with or without it.

4.4 ShapeModule

Draws shapes, backgrounds and progress bars.

PropertyTypeDescription
shape_typeStringSeen in the real preset: RECT, CIRCLE, ARC verified. Also documented: OVAL, EXAGON, PATH unconfirmed.
shape_width / _heightNumberPixels, written as floats such as 546.0. Can be bound to globals (toggle 100) or formulas (toggle 10) verified.
shape_cornersNumberCorner radius, for example 52.0. 360 makes it fully rounded.
shape_angleNumberArc sweep in degrees. The wave crests use 90.0 verified.
shape_rotate_modeString"DEG180" flips an arc into a trough verified.
paint_colorColor#AARRGGBB, for example #00FFFFFF for fully transparent verified.

4.5 TextModule / CurvedTextModule

Static text, formulas or media info. The real preset uses TextModule for title and artist and CurvedTextModule for the time and output labels.

PropertyTypeDescription
text_expressionFormulaThe text or formula, set directly on the property verified. Supports BBcode such as [b]. Bare words work as strings, for example This Phone.
text_familyStringFont path such as kfile://org.kustom.provider/fonts/ProductSans-Medium.ttf verified.
text_sizeNumberFloat, for example 32.0 verified.
text_alignStringLEFT, CENTER, RIGHT unconfirmed.
paint_colorColorHex color. Often bound to a global with toggle 100. Absent on the title, which uses the default.
fx_shadow*StringText shares the shape shadow properties (section 6) verified.
position_padding_*NumberUsed for placement, for example the Position label uses BOTTOMLEFT with left 36 and bottom 45 verified.

4.6 BitmapModule

Displays images such as album covers and app icons.

PropertyTypeDescription
bitmap_bitmapFormulaSet through internal_formulas with "bitmap_bitmap": 10 in internal_toggles, with no static property verified. Example: $ni(mi(package), icon)$ returns the playing app icon. A plain file path is unconfirmed.
bitmap_width / _heightNumberDimensions, for example 34.0 and 36.0 verified.
bitmap_filterString"COLORIZE" tints the image verified.
bitmap_filter_colorColorTint color, often bound to a global with toggle 100 verified.

Earlier versions of this page showed bitmap_bitmap as a plain property holding $mi(cover)$. The real preset does not do that.

4.7 FontIconModule

Displays icons from an icon font.

PropertyTypeDescription
icon_iconFormulaIcon name, for example skip_next, skip_previous, music_note, headset_mic verified. A dynamic icon uses internal_formulas with "icon_icon": 10 and also keeps a static icon_icon fallback. Names in formulas are bare words: $if(mi(state) = PLAYING, Pause, Play_arrow)$ verified.
icon_sizeNumberPixels, for example 42.0, 52.0.
icon_setStringOptional path to an icon font. Most icons in the real preset omit it and still resolve Material names such as skip_next verified.
paint_colorColorIcon color, often bound to a global.

5. Global Bindings & Overrides

Any property can be driven by a static value, a formula or a global.

internal_toggles

Selects which source is active for each property verified. The formula or global is ignored unless the toggle selects it.

ToggleActive source
0The static value. A stored formula or global is inactive.
10The formula in internal_formulas.
100The global named in internal_globals.
"internal_toggles": { "paint_color": 100, "shape_width": 10 },
"internal_globals": { "paint_color": "accent" },
"internal_formulas": { "shape_width": "$gv(pbwidth)*(mi(percent)/100)-1$" }

When the toggle is 100 the static property is optional: the real preset has 26 such properties without one and 11 with one.

internal_globals

Binds a property to a global name. This works for sizes too: "shape_width": "bgwidth" verified.

internal_formulas

Overrides a property with a formula or multi-line script. Values appear with or without $...$ wrapping.

6. Advanced FX & Masks

Mostly on ShapeModule and containers.

PropertyTypeDescription
fx_maskStringCLIP_ALL or CLIP_NEXT verified.
fx_gradientStringRADIAL and BITMAP seen verified. It can be set by formula, for example $if(mi(state)=NONE, NONE, RADIAL)$, so NONE is a valid value. LINEAR is unconfirmed.
fx_gradient_bitmapFormulaImage used by a BITMAP gradient. The real preset sets $mi(cover)$ through internal_formulas with toggle 10 verified.
fx_gradient_colorColorGradient color, bound to a global with toggle 100 verified.
fx_bitmap_dimNumberDarkness of the bitmap overlay (24.0, 38, 40.0 seen) verified.
fx_gradient_offsetNumberSpread position (100 seen) verified.
fx_shadowStringOUTER seen verified. INNER is unconfirmed.
fx_shadow_colorColorShadow color, for example #80000000.
fx_shadow_blurNumberBlur radius.
fx_shadow_distanceNumberDistance the shadow is cast.
fx_shadow_directionNumberAngle of the shadow. Only 0 appears, so the 0-degree direction is unconfirmed.

7. Events (internal_events)

Touch interactions, allowed on any module verified.

PropertyTypeDescription
typeStringSINGLE_TAP seen verified. DOUBLE_TAP and LONG_TAP are unconfirmed. May be omitted at root level.
actionStringMUSIC seen verified. LAUNCH_APP, KUSTOM_ACTION, DISABLED are unconfirmed.
music_actionStringNEXT, PREVIOUS, OPEN_APP verified. Play/pause has no music_action.
intentStringAndroid intent URI for launching apps unconfirmed.
{ "type": "SINGLE_TAP", "action": "MUSIC", "music_action": "NEXT" }       // next track
{ "type": "SINGLE_TAP", "action": "MUSIC", "music_action": "PREVIOUS" }   // previous track
{ "type": "SINGLE_TAP", "action": "MUSIC" }                               // play / pause
{ "type": "SINGLE_TAP", "action": "MUSIC", "music_action": "OPEN_APP" }   // open the player
// root level, no type:
{ "action": "MUSIC", "music_action": "OPEN_APP" }

9. Edge Cases & Undocumented Mechanics

These are specific quirks found in the JSON files that the compiler must handle correctly.

1. Multi-line Scripts in Formulas
internal_formulas can contain line breaks (\n) to execute sequential logic.
2. Built-in Globals (e.g., h)
In the Weather widget, shape_height is bound to a global named h. h and w are built-in KWGT variables representing the Root widget's height/width.
3. The config_visible Toggle Trap
Setting a formula for config_visible does nothing unless "config_visible": 10 is present inside internal_toggles.
4. Global Scope Isolation in Komponents
A KomponentModule can have its own globals_list. These globals do not leak to the Root, and their indices often start at numbers other than 1.
5. Font File Paths
All font and image paths use the kfile:// protocol.
6. Bare Words, Not Quotes
String results in formulas are usually bare words: $if(mi(state) = PLAYING, Pause, Play_arrow)$, Nothing playing. Comparisons use = and !=, and | combines conditions. verified
7. Formula Wrapping
Most formulas are written $...$, but some stored ones are bare, such as the Komponent's config_visible. Both forms are accepted. verified

10. Absolute Edge Cases & Exact Quirks

These represent the deepest structural anomalies in the JSON files that a compiler must replicate exactly.

1. Two-Line Script Formulas
In the Media Player progress bar, a formula uses \n to create a local variable on one line and evaluate it on the next: 
"internal_formulas": {
  "position_padding_left": "$lv(\"w\",gv(pbwidth)*(mi(percent)/100))$\n$if(lv(w)<=0, \"0\", lv(w)-8)$"
}
If the \n is stripped or converted to a space, KWGT will throw a formula error.
2. Negative Float Precision
Stack margins are highly precise floats. In the Media Player, the wave effect relies on: "config_margin": -4.4 The compiler must preserve this exact decimal value.
3. Exact Shape Spelling
The Weather widget explicitly uses "shape_type": "EXAGON" (not HEXAGON). The Media Player uses "CIRCLE" instead of OVAL. Do not autocorrect these spellings.

11. Fallbacks & Event Variations

Anomalies regarding static properties and root events.

1. Static Fallbacks Coexisting with Globals
Even when a property is bound to a global variable or formula, presets usually keep the static property as a fallback. It is optional when the toggle is 100 (section 12). In the Time Date Info widget, the "BG" shape has both a global binding and a static color: 
"internal_globals": {
  "paint_color": "bgcolor"
},
"paint_color": "#FF000000"
A compiler should output a static fallback when the source node has one, and may omit it when it has none.
2. Root Event Variations (Missing `"type"`)
The root internal_events array is highly inconsistent across widgets. Variation A (Time Date Info): No type, uses KUSTOM_ACTION. 
"internal_events": [
  { "action": "KUSTOM_ACTION" }
]
Variation B (NothingTemp): Explicit type, disabled action. 
"internal_events": [
  { "type": "SINGLE_TAP", "action": "DISABLED" }
]
Variation C (Media Player): No type, but specifies a music action. 
"internal_events": [
  { "action": "MUSIC", "music_action": "OPEN_APP" }
]
The compiler must not assume "type": "SINGLE_TAP" is required at the Root level.

12. Final Structural Variations

The last remaining edge-cases found in the Media Player and Date widgets.

1. Missing Static Properties (No Fallback)
While the Date widget included a static fallback paint_color, the Media Player progress bar "Clip Bg" shape explicitly omits the static property entirely, relying only on the global: 
"internal_type": "ShapeModule",
"internal_toggles": { "paint_color": 100, "shape_width": 10 },
"internal_globals": { "paint_color": "fg-color" }
// NO "paint_color" static property exists here.
The compiler must be capable of omitting the static fallback if the original Penpot node doesn't have one.
2. Container-Level Events
Events are not limited to the Root or Leaf shapes. The Media Player attaches an event to an OverlapLayerModule named "Output": 
"internal_type": "OverlapLayerModule",
"internal_title": "Output",
"internal_events": [
  { "type": "SINGLE_TAP", "action": "MUSIC", "music_action": "OPEN_APP" }
]
Any module type can accept an internal_events array.
3. Custom Font Paths in Icons
The FontIconModule can point to a custom font bundled inside the widget's own ZIP archive, rather than the system font: 
"icon_set": "kfile://org.kustom.provider/widgets/Material3_Media_Player.kwgt/icons/material.ttf"
4. Text Modules Use Shape FX Shadows
Text modules (CurvedTextModule) use the exact same shadow FX properties as Shape modules: 
"fx_shadow": "OUTER",
"fx_shadow_blur": 41,
"fx_shadow_direction": 0,
"fx_shadow_distance": 0,
"fx_shadow_color": "#80000000"

13. Package & Install (The .kwgt Container)

A .kwgt file is a ZIP archive with preset.json at its root.

MyWidget.kwgt (ZIP archive)
│
├── preset.json (required, at the root of the ZIP)
├── preset_thumb_portrait.jpg (preview image)
├── preset_thumb_landscape.jpg (preview image)
├── bitmaps/ (optional - images)
├── fonts/ (optional - custom fonts)
└── icons/ (optional - icon fonts, for example material.ttf)
Thumbnails. Generated files that contain preset.json plus the two thumbnails load in KWGT and show the preview on the preset card verified. Whether KWGT loads a file without thumbnails is unconfirmed.

Linking files via kfile://

"text_family": "kfile://org.kustom.provider/widgets/MyWidget.kwgt/fonts/CustomFont.ttf"
"bitmap_bitmap": "kfile://org.kustom.provider/widgets/MyWidget.kwgt/bitmaps/image1.png"
"icon_set": "kfile://org.kustom.provider/widgets/Material3_Media_Player.kwgt/icons/material.ttf"
"text_family": "kfile://org.kustom.provider/fonts/ProductSans.ttf"   // built-in font, no widget name

Bundled paths include the .kwgt file name, so renaming the file breaks them.

Installing

  1. Copy the .kwgt file to the phone.
  2. Either open it from KWGT's load option, or place it in Kustom > widgets on internal storage and open KWGT's Installed tab.
  3. Add a KWGT widget to the home screen, pick the preset and tap Save.

Troubleshooting

IssueCauseSolution

14. Verified & Open Questions

Confirmed

  • Draw order: the first array item is the bottom layer.
  • Toggles: 0 = static, 10 = formula, 100 = global.
  • globals_list is an object keyed by name.
  • Play/pause is {"type":"SINGLE_TAP","action":"MUSIC"}; mi(state) returns NONE, STOPPED or PLAYING.
  • Bitmap sources are set by formula through internal_formulas (toggle 10).
  • Generated presets using RootLayerModule, ShapeModule RECT, paint_color, TOPLEFT anchors and offsets load and display in KWGT.

Still unknown

  • How preset_info width and height relate to the widget size placed on a home screen.
  • What config_scale_value does, and how a container sizes itself from its children.
  • Rotation and flip, strokes, gradient color stops and angle, text box width and spacing, bitmap fit modes, PATH data.
  • The text_align property, DOUBLE_TAP/LONG_TAP, and the shadow direction convention.
  • Other config_stacking values.
