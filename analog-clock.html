Analog clock

A Nothing OS style analog clock by Om Gupta (RootLayerModule, 415 x 542, features: "ANALOG_CLOCK", version 13). Everything scales from one number, side, so the face stays correct at any widget size. Drag the slider and watch the hand sizes.

Live time. Tick sizes are approximated from your screenshot; hand sizes come straight from the formulas.

1. Layers, bottom to top

Root
├─ Border            CIRCLE, width = side, color = bg global
├─ Hours Hand        Overlap, config_rotate_mode CLOCK_HOUR_SMOOTH
├─ Minutes Hand      Overlap, config_rotate_mode CLOCK_MINUTE
├─ Seconds Hand      Overlap, rotate mode CLOCK_SECOND (set by formula)
├─ ProgressModule    12 hour ticks
├─ ProgressModule    60 minute ticks
└─ center dot        CIRCLE, seconds color

2. The scaling trick

The side global is the smaller of width and height. Every size is written as side/(277/N), which is just N x side / 277: the face was designed at 277 px and everything scales with it.

"side": { "index": 7, "type": "NUMBER", "title": "side", "min": 0, "max": 720, "toggles": 10,
  "global_formula": "$if(si(rwidth)>si(rheight), si(rheight), si(rwidth))$" }

"internal_formulas": { "shape_width": "$gv(side)/(277/6)$",
                       "shape_height": "$gv(side)/(277/74)$",
                       "position_padding_bottom": "$gv(side)/(277/64)$" }

Because the formulas win when the toggle is 10, the static shape_width: 6.0 next to them is only a fallback. Keep the static value near the formula’s result.

3. Colors that follow dark mode

Color globals can be driven by formulas (toggles: 10) and keep a static value fallback:

"bg":   { "index": 3, "type": "COLOR", "title": "Bg", "value": "#FF1B1B1D", "toggles": 10,
          "global_formula": "$if(si(darkmode)=1, #FF1B1B1D, #FFFFFFFF)$" },
"hour": { ... "global_formula": "$if(si(darkmode)=1, #FFFFFFFF, #FF1B1B1D)$" },
"seconds": { "index": 6, "type": "COLOR", "title": "Seconds", "value": "#FFD71921" }

The minute color’s fallback (#FF6C696E) differs from its formula; with toggle 10 the formula is what you see. The red seconds color has no formula, so it never changes.

4. Rotation: hands that turn by themselves

PropertyMeaning
config_rotate_modeOn a container. CLOCK_HOUR_SMOOTH, CLOCK_MINUTE, CLOCK_SECOND turn the whole container like a clock hand. MANUAL uses a fixed angle.
config_rotate_offsetExtra degrees. The seconds hand uses 90.

The seconds hand shows an odd pattern: the static mode is MANUAL, but toggle 10 plus the formula CLOCK_SECOND switches it to the clock mode. Its rectangle is horizontal (130 x 3, position_padding_right: 100), and the 90 degree offset turns it upright.

{ "internal_type": "OverlapLayerModule", "internal_title": "Seconds Hand",
  "config_rotate_mode": "MANUAL", "config_rotate_offset": 90.0,
  "internal_toggles": { "config_rotate_mode": 10 },
  "internal_formulas": { "config_rotate_mode": "CLOCK_SECOND" }, "viewgroup_items": [ ... ] }
My reading of the screenshot. A centered module with position_padding_bottom: 64 and height 74 reaches about 69 px above the center and a few px past it. That fits the module shifting by half the padding. The demo above is drawn that way and matches your screenshot. This is inference, not a documented rule.

5. Tick marks with ProgressModule

A new module type, ProgressModule, draws repeated shapes around a circle. Two copies make the ticks: 12 big ones and 60 small ones.

PropertyHour ticksMinute ticks
progress_progressCUSTOMCUSTOM
progress_max / progress_level12 / 1260 / 60
progress_modeSHAPESSHAPES
progress_count1260
style_styleCIRCLE (arranged in a ring)CIRCLE
style_size250 (ring diameter)258
style_shapeRECTRECT
style_width / style_height8 / 1611 / 8

Colors come from globals with toggle 100 (color_fgcolor, color_bgcolor). The size properties use the same side formulas as everything else. Since the level equals the max, every tick is drawn.

6. Border, center dot and tap

  • Border is a CIRCLE with paint_stroke: 3.0 (a stroke width, new here) and its size bound to side.
  • The center dot is a pill (shape_corners: 360), width side/(277/16), in the seconds color.
  • The root tap opens the Clock app with an intent (see Events).

7. Leftovers worth knowing

  • The root stores a config_scale_value formula ($mu(floor, ...)/3$) and points at a global called radius, but its toggle is 0 and no such global exists, so it does nothing. Stored but inactive, like the Komponent visibility formula earlier.
  • mu(floor, x) is a math function (new in these docs).
  • The minute hand has toggle 10 for shape_width but no stored formula. Only the static 6.0 exists, so it is what you get.
