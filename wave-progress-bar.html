Wave progress bar

This is Om Gupta’s Wave Progress Bar, the Material You style bar from the media player: a wavy line while music plays, a straight line when it does not, plus previous and next buttons. Below is how it is built. Explanations of why a trick works (the clip masks) are my reading of the file, not confirmed against KWGT’s source.

Live preview below is a simplified straight-line version. The simulator cannot draw ARC shapes or fx_mask clipping, so there is no wave. It does show the formulas, globals, head and taps. Drag progress.

1. The layer tree

Wave Progress Bar (KomponentModule)
└─ Bottom Controls (Stack, BOTTOM, margin 32)
   ├─ Previous (icon)
   ├─ Progress Bar (Overlap)
   │   ├─ Clip Bg           mask CLIP_NEXT
   │   ├─ Background Container
   │   ├─ Clip Wave         mask CLIP_NEXT
   │   ├─ Line Progress     visible when NOT playing
   │   ├─ Wave Progress     visible when playing
   │   └─ Head
   └─ Next (icon)

2. Layers, bottom to top

LayerWhat it does
Clip BgA 23 px tall rectangle anchored CENTERRIGHT. Width = $gv(pbwidth)*(1-mi(percent)/100)+6$, so it covers the unplayed part. fx_mask: CLIP_NEXT clips the layer after it.
Background ContainerThe faint track: 4.5 px high, corners 360, width $gv(pbwidth)+1$, color #66FFFFFF. Its paint_color toggle is 0, so the stored sc-color global is inactive. Only the plain color is used.
Clip WaveSame idea on the left: anchored CENTERLEFT, width $gv(pbwidth)*(mi(percent)/100)-1$, the played part, also CLIP_NEXT.
Line ProgressA straight 4 px line, width bound to pbwidth (toggle 100). Visible when mi(state)!=PLAYING.
Wave ProgressThe wavy line (section 4). Visible when mi(state)=PLAYING.
HeadThe 8 x 32 pill that marks the position (section 3).

3. The head: a two-line formula

The head’s left padding is a multi-line script. Line one stores the played width in a local variable, line two subtracts 8 so the pill is centered on the edge and never goes negative.

"position_padding_left": "$lv(\"w\",gv(pbwidth)*(mi(percent)/100))$\n$if(lv(w)<=0, \"0\", lv(w)-8)$"

The toggle for it is "position_padding_left": 10 and there is no plain value. Keep the \n; a space breaks the formula.

4. Building the wave

  • One Cycle is a horizontal stack of two ARC shapes, 30 px wide and 4.5 px tall, each with shape_angle: 90.
  • The second arc has shape_rotate_mode: "DEG180" and position_padding_top: 27, so it flips into a trough.
  • config_margin: -4.4 on the stacks makes neighbors overlap so the curves join smoothly. Keep that exact decimal.
  • The file repeats the Cycle 8 times, after a round Cap Start (CIRCLE, 4.5 px). Add more Cycles for a longer wave.

5. Controls

The root of the komponent is a StackLayerModule anchored BOTTOM with config_margin: 32, holding Previous, the progress bar and Next. The icons are 42 px and use fg-color (toggle 100). Their taps are {"type":"SINGLE_TAP","action":"MUSIC","music_action":"PREVIOUS"} and "NEXT".

Try it yourself

  • Change fg-color to recolor everything.
  • Change $si(rwidth)/2.3$ to /2 for a longer bar.
  • Swap the visible formulas to always show the wave.
